# Stata解析コード

[English](README.md) | 日本語

肝外転移を伴う大腸癌肝転移について、B群（肝切除・肝外非切除）とC群（肝非切除・肝外非切除）を比較した既存コードの公開用コピーです。実データは配布しません。

## 含めた処理

`master.do`は、非公開の整理・クリーニング済みデータから、多重代入、傾向スコア・重みの作成、共変量バランス・重なりの評価、記述統計、生存時間解析を順に呼び出します。全体、原発巣手術あり、肺限定の3集団に対応します。データ整理・クリーニングのコード5本（`crDataICL01*.do`4本と`map2cat.ado`）は公開対象から除外しました。

- `crDataICL02_mi.do`：22セットの多重代入。欠測への統計的方法として保持し、乱数seedは元コードの値を使用。
- `crDataICL03_mi_ps.do`：欠測指標を含むロジスティック回帰から、補完セットごとに傾向スコアと重みを作成。交絡調整の統計的方法として保持。
- `anEvalPS01_covbal.do`、`bal_sIPTW.ado`：外部Stataコマンド`covbal`を使い、22補完セットそれぞれの重み付け前後のSMD・分散比を計算してExcelに出力。
- `anEvalPS02_overlap.do`、`anDes01.do`：重なりの図、記述統計。
- `anSurv01mi.do`：重み付け前後のCox、Weibull PHおよびWeibull AFTモデルを実行し、22補完セットの推定値を統合します。また、第1補完セットを使い、重み付け前後のKM曲線、生存期間中央値、ログランク検定、36・60か月時点の生存率（追跡期間が短い場合は利用可能な時点まで）を出力します。

Pythonは上記のSMD・分散比の計算には不要です。既存の[補助Python](../python/historical/README_JP.md)は、Stataで出力した補完セット別Excelの値を平均する後処理であり、`master.do`からは呼び出しません。Rで行われる別のバランス評価を含めた整理は[全体の説明](../README_JP.md)を参照してください。

原発巣手術あり＋肺限定の組合せは、元の`master.do`で傾向スコア推定が非収束のため無効化されていた検討段階の処理です。公開版にはこの組合せのデータ整備・多重代入・無効化済み推定呼出しを含めません。

## 実行環境と入力

Stata 18以降を必要とします（`anDes01.do`が`dtable`を使用）。元の解析を実行したStataの正確な版と、外部コマンドの版は、2026-09-08の初回準備時の静的確認では確定していません。2026-09-14に行った実行検証の環境・確認範囲は[全体の説明](../README_JP.md)を参照してください。外部コマンド`covbal`を別途利用可能にしてください。起動用コードは不足を確認しますが、自動インストールはしません。

1. 非公開の作業用コピーを作り、Stataの作業ディレクトリをその`stata`フォルダに設定します。
2. 利用権限のある多重代入前の整理・クリーニング済みデータ3本を、このフォルダに用意します。

   | ファイル | 対象集団 |
   |---|---|
   | `df01mi.dta` | 全体 |
   | `df01mi_surgery.dta` | 原発巣手術あり |
   | `df01mi_lung.dta` | 肺限定 |

3. 入力を[コードブック](../codebook/README_JP.md)の変数名・符号化・型・単位に合わせます。6つの補完対象の旧欠測カテゴリはStataのシステム欠損`.`に戻し、補完前の欠測指標`grade_mind`、`primary_n_mind`、`tumor_count_cat_mind`、`tumor_size_cat_mind`、`cea_cat_mind`、`ca199_cat_mind`を既に作成してあることが前提です。これらの整備処理は公開コードに含めません。
4. `do run_public.do`を実行します。

`run_public.do`は入力3本、`master.do`、ローカル補助関数`bal_sIPTW.ado`、外部コマンド、Stata版の存在・要件を確認します。入力の内容や符号化の適合性を自動検証するものではありません。ローカル補助関数を探索対象に加え、Excel・図の出力フォルダを作り、`master.do`を実行します。元コードどおり、同名の中間データ・出力は再実行で上書きされます。入力3本を保存・変更する処理はありません。

中間の`.dta`、第1補完セットのテスト用データ、実行後のExcel・グラフ等は公開対象ではありません。入力に症例識別子や手術日が含まれる場合は中間データにも残るため、作成された出力をそのまま公開しないでください。`master.do`末尾にあった症例単位Excel書き出しのコードは公開版から削除しました。

## 既存版と既知の制限

- 現在の公開用`anSurv01mi.do`では、コメントアウトされていた重み付け前後のKM曲線、生存期間中央値、ログランク検定、生存率の2ブロックを有効化しています。これらはCox・Weibull PH/AFTモデルとともに、`master.do`から3集団すべてについて実行されます。
- `historical/anSurv01mi.do`は参照用に保持しています。元プロジェクトのRMST作業フォルダに保存されていた、AFT追加前の版です。`master.do`からは呼び出さず、標準の手順でKM曲線等を作成するために別途実行する必要もありません。
- 肺限定は元データの`EHD分類2 == "M1 (Lung)"`、解析変数の`ehd2==0`に対応します。他臓器との多発を含む「肺転移のある全例」とは異なります。集団の抽出は非公開の入力準備で完了させます。
- 重なりの図と記述統計、および現在版・historical版のKM曲線等は、第1補完セット（`_mi_m == 1`）を使う実装です。これらを22セット統合の推定値とは扱いません。Cox・Weibull PH/AFTモデルの回帰推定値は、`mi estimate`で統合します。
- `event_os`の定義は0＝生存／打切り、1＝死亡です。元の整理コードには転帰ラベル名の綴りの不一致があるため、コードブックに定義根拠を記録しています。
- 採用した3集団のモデル仕様、重み式、乱数seed、解析コード内の症例選択、欠測値・完全予測への対応は元コードから保持しています。記述的な生存時間解析のブロックを有効化したことで、標準の手順から得られる出力が増えています。実行検証の範囲と残る制限は[全体の説明](../README_JP.md)を参照してください。
