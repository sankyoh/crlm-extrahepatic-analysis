# 肝外転移を伴う大腸癌肝転移の解析コード

[English](README.md) | 日本語

Analysis code for colorectal liver metastases with extrahepatic disease.

既存プロジェクトから研究解析コードを選定した、GitHub・Zenodo公開準備用のフォルダです。準備日: 2026-09-08。元ファイルを変更せず、公開用コピーの個人用パス・内部リンク等を整理しています。患者単位のデータセットは含みません。

## 解析の範囲

B群は肝切除・肝外非切除、C群は肝・肝外とも非切除です。StataにはB/C全体、原発巣手術あり、肺限定の解析を収載しています。肺限定は `EHD分類2 == "M1 (Lung)"` の区分であり、多臓器転移を含むすべての肺転移例を意味しません。

現在のStata生存解析コードには、Cox・Weibull比例ハザードモデル、Weibull AFTによる時間比に加え、非加重・加重のKM曲線、生存期間中央値、ログランク検定、追跡期間に応じた36・60か月生存率の算出を含みます。KM曲線等の記述的解析は第1補完セットを使用し、回帰解析は22補完セットを統合します。現在版は `master.do` から呼び出されます。`stata/historical/` の旧版は参照用に保持しており、KM曲線等の作成に別途実行する必要はありません。

RのRMSTコードは `_mi_m=1` のみを使う既存の検証解析です。22セットを統合したRMST解析は実装されておらず、区間推定に補完間の変動を含みません。最終原稿との対応、R側の対象制限・重み再計算、共変量バランスの指標名など、既知の確認事項は各フォルダのREADMEに記載しています。

## 再現性の確認範囲と既知の制限

2026-09-14に、整備済みの非公開データを用いて以下の検証を実施しました。Stataの検証環境はStata 19.5および外部コマンド `covbal` 1.1.1です。データ整理・クリーニングは検証範囲に含まず、利用者が数値結果を再現するには、必要な入力データと実行環境を別途用意する必要があります。

以下の補完データ・PS／重みの一致確認は、先行する全手順の検証結果です。KM部分の有効化後には、保存済みの補完・重み付きデータを用いて、現在の生存解析コードを3集団で別途実行しました。この追加確認では、多重代入やPS推定を再実行していません。

| 対象 | 確認済みの範囲と制限 |
| --- | --- |
| 多重代入・PS・重み・Cox／Weibull解析 | 全体・原発巣手術あり・肺限定の3集団で、標準手順の正常終了を確認しました。各集団で再生成した補完後データおよびPS・重み付きデータ（計6本）は、保存済みの対応データと全変数の値が完全に一致しました。 |
| KM曲線・生存期間中央値等 | 現在の[生存解析コード](stata/anSurv01mi.do)で有効になっており、標準の `master.do` から実行されます。第1補完セットを使用します。有効化後の現在版を保存済みの補完・重み付きデータで実行し、3集団とも正常終了を確認しました。現在の手順は [Stata README](stata/README_JP.md) を参照してください。 |
| 共変量バランスの完成表 | **現状の公開コードだけでは、保存済みの完成表を完全には再現できません。** 全体集団のCA19-9の2行はPythonによる22補完セットの平均対象から外れています。完成表の該当値は第1補完セットの値と一致し、22セットの平均とは一致しません。また、Excel上で行われている符号反転・分散比の逆数化等の仕上げ処理は、公開コードに含まれていません。 |
| RのRMST | 第1補完セット（`_mi_m=1`）を用いる解析コードを収載しています。上記の検証では必要なRパッケージが検証環境に揃っていなかったため、再実行および数値一致は未確認です。環境の準備手順は [R README](r/README_JP.md) を参照してください。22補完セットを統合するRMST解析は実装されていません。 |

全変数の値の一致は、上記の補完後データとPS・重み付きデータについて確認したものです。論文本文・掲載図表の全数値との一致や、研究方法全体の妥当性を検証したものではありません。

## 共変量バランス表の作成経路

| 処理 | 実装 |
| --- | --- |
| 各補完セットの非加重・加重SMDと分散比の計算 | Stataの `anEvalPS01_covbal.do` → `bal_sIPTW.ado` → 外部コマンド `covbal`。各集団22個のExcelを作成 |
| 22セット分の加重後SMD・分散比の平均 | `python/historical/` の補助コード。患者データのクリーニングを行うものではない |
| 表に添える記述統計 | Stataの `anDes01.do`。第1補完セットから `dtable` で作成 |
| 第1補完セットによる別のRMST検証のバランス診断 | Rの `run_wrmst_analysis.R` 内の `cobalt::bal.tab()`。診断CSVを出力 |

原プロジェクトにはStataの補完別Excel、Python平均出力、Rの診断CSVが残っています。保存済みの仕上げ用バランス表Excelには符号反転・逆数の数式がありますが、22セットを平均する数式はありませんでした。プロジェクト内に、Python以外で既存の22セット平均を行った実装は確認できていません。Rの第1補完セット診断を、その平均表の代替として扱うことはできません。

## 実行

実データは別途、利用権限のある非公開環境で用意する必要があります。公開用フォルダだけで数値結果を再現することはできません。入力の列名・符号化は [コードブック](codebook/README_JP.md) を参照してください。

- Stata: 非公開の作業用コピーの `stata` フォルダに整備済みの `df01mi.dta`、`df01mi_surgery.dta`、`df01mi_lung.dta` を用意し、同フォルダを作業ディレクトリにして `do run_public.do`。補完前の変数定義・欠測指標が必要です。入力要件と外部コマンド等は [Stata README](stata/README_JP.md) を参照。
- R: [R README](r/README_JP.md) の手順で、入力 `.dta` と非公開出力先を明示して実行。
- Pythonの過去コード: [専用README](python/historical/README_JP.md) に記載した範囲・制限を確認して使用。

実行すると、元の処理に従い中間データや結果を生成し、同名の既存出力を上書きします。生成されるデータ、RDS、ログ、Excel、イベント時刻を含む曲線出力等は公開用コードブックとは別物です。これらは非公開で管理してください。

`.gitignore` は、この準備で確認したファイルを個別に許可する方式です。データや出力を誤って追加しにくくしています。今後新しい公開ファイルを加える際は、中身を確認したうえで許可対象を更新してください。無視ルールは、強制追加や既に追跡されたファイルを保護するものではありません。
