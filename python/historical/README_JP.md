# 共変量バランス出力を平均する過去の処理

[English](README.md) | 日本語

これらのスクリプトは、3本の解析ノートブックに含まれていたPythonコードを保存したものです。過去の手順を記録する補助コードであり、共変量バランスを要約する現行手法として検証済みではありません。ノートブック本体、保存された出力・メタデータ、Excelファイルは同梱していません。

各補完セットのSMDと分散比は、Stataが `covbal` を使って計算します。これらのPythonスクリプトは、計算済みの重み付け後の結果を平均します。患者データのクリーニング、アウトカムモデルの推定、RMSTの計算は行いません。データセットのクリーニングコードを除外した公開範囲にも、引き続き収載しています。

元の3本のノートブックに保存された実行記録では、欠落ファイルのメッセージなしに22ファイルすべてを読み込み、出力に成功しています。保存された平均値出力は、作成済みの共変量バランス表と対応しています。全体集団では選択対象の全セルが一致し、手術あり集団と肺群ではSMDの全セルが一致します。手術あり集団と肺群では、それぞれ3つの分散比のセルが完成表で逆数になっています。そのExcelファイルには符号反転と逆数化の数式がありますが、22補完セットを平均する数式はありません。これらは表作成に使われたことを支持しますが、論文の最終表の全行を厳密に再現できることを示すものではありません。

## 出典と保持した数値選択範囲

以下の元ファイルのパスは、原プロジェクトの非公開フォルダからの相対パスです。元のノートブックは変更せずに読み取っています。

| 公開スクリプト | 元のノートブック | 保持した `iloc` 行範囲 | 実際のExcelセル | 出力行数 |
| --- | --- | --- | --- | --- |
| `average_balance_surgery.py` | `stata/excel/surgery_only/Cell_mean_of_22files.ipynb` | `2:25` | F3:G25 | 23 |
| `average_balance_lung.py` | `stata/excel/lung_only/Cell_mean_of_22files.ipynb` | `2:22` | F3:G22 | 20 |
| `average_balance_all.py` | `stata/excel/mimi_stbw/Cell_mean_of_22files.ipynb` | `2:23` | F3:G23 | 21 |

各スクリプトは `mimi_stbw_1_smdvr.xlsx` から `mimi_stbw_22_smdvr.xlsx` を入力とし、`header=None` で `SMD_VR` シートを読み込み、列 `5:7`（ExcelのF列とG列）を選択します。これらの設定は変更せずにコピーしています。

現行のStataのmasterは、全体集団のバランス出力を `excel/all` に保存します。一方、過去の全体集団用ノートブックは `excel/mimi_stbw` に置かれていました。公開する `average_balance_all.py` は後者のノートブックのコードであり、ファイル名の変更によって現行の `excel/all` 出力に行選択が適合すると確認されたわけではありません。利用者が意図した非公開入力を選べるよう、コマンドラインでフォルダを明示的に指定する方式にしています。現行Stataの手術あり集団と肺群のフォルダは、それぞれ `excel/surgery_only` と `excel/lung_only` です。

## 非公開の出力ファイルを使った実行

Pythonでは `numpy`、`pandas`、`openpyxl` が必要です。元のノートブックでは依存パッケージのバージョンを固定していません。パッケージは別途インストールしてください。ノートブックのインストール用セルは、実行可能なスクリプトから削除しています。

```text
python -m pip install numpy pandas openpyxl
python python/historical/average_balance_surgery.py PRIVATE_SURGERY_FOLDER
python python/historical/average_balance_lung.py PRIVATE_LUNG_FOLDER
python python/historical/average_balance_all.py PRIVATE_ALL_FOLDER
```

リポジトリ直下から実行し、各プレースホルダを利用権限のある非公開フォルダに置き換えてください。リポジトリの外のフォルダを推奨します。空白を含むパスは引用符で囲んでください。各スクリプトは入力フォルダに `mean_F3_G23.xlsx` を書き込み、同名の既存ファイルがあれば上書きします。入力と生成された出力は非公開で管理し、Gitの対象外とする必要があります。ここではソースコードのみを提供しています。

## 過去の手順の制限

- 手術あり集団と肺群のスクリプトでは、上表のとおり実際の行範囲が異なる一方、F3:G23に言及するコメントと出力ファイル名を保持しています。選択対象の行がすべて存在する場合、手術あり集団は23行、肺群は20行を出力します。21行を出力すると説明する元のコメントも変更していません。選択範囲を決めるのはコメントやファイル名ではありません。
- 行・列の固定位置で選択します。変数名、行の対応、意図した現行のバランス指標がすべて含まれるかは検証しません。別の版の出力でもF列とG列の意味が同じかは確認しません。結果の解釈前に入力Excelファイルの配置を確認してください。
- 全体集団のスクリプトは21行を選択します。このため、現行のStataの23行のバランス出力では、末尾のCA19-9の2カテゴリ行がこの範囲から外れます。この過去の選択範囲だけでは、その表の全行を再現できません。
- 見つからないファイルは報告して読み飛ばします。そのため、22より少ない補完セットを平均する場合があります。数値以外のセルは `NaN` に変換され、`nanmean` はそれらを除外するため、計算に寄与するファイル数はセルごとに異なる可能性があります。選択された配列の形が異なると、積み重ねる処理が失敗することがあります。すべてが欠測のセルは欠測のままです。
- 対応するセルの単純な算術平均を計算します。Rubinのルールによる推定値の統合、補完に伴う不確実性の考慮、すべての補完セットでバランスが十分かの確認は行いません。
- 処理の出典を保持するため、上記の行範囲と動作をそのまま残しています。2026-09-08の初回の公開準備では、患者データを用いた解析や数値の再現性の検証は行っていません。スクリプトの確認はPythonの構文解析のみです。

## 公開用コピーの変更点

コードセルを通常のPythonファイルに書き出し、ノートブックの出力とメタデータは除外しました。ノートブックのインストール用セルは、上記の手動インストールコマンドの説明に置き換え、インポートされる `numpy` も依存パッケージとして明記しています。個人の端末に固有のフォルダパスは削除し、必須のコマンドライン引数 `private_folder` に置き換えました。入力フォルダと出力パスの設定は `main(private_folder)` 内で行い、既存の出力ファイル名は保持しています。過去のコードであることを示す短いdocstringとコマンドラインヘルプを追加しました。元の数値定数、ファイル選択処理、欠落ファイルの処理、数値への変換、平均計算、Excel出力オプションはすべて保持しています。
