# Rによる補足的なRMST検証

[English](README.md) | 日本語

このフォルダには、実装済みの制限平均生存時間（RMST）の検証手順を収載しています。使用するのは**22セットの補完済みデータのうち、第1セットのみ**（`_mi_m = 1`）です。多重代入の結果を統合する処理はなく、最終的な統合RMST解析として説明することはできません。原プロジェクトでは、この手順を暫定的なものとして記録しています。

## 収載内容と入力

- `scripts/run_wrmst_analysis.R`：36か月・60か月の、重みなしおよび安定化逆確率治療重みを用いたKaplan–Meier法によるRMST、B群からC群を引いた群間差、診断用の出力を作成します。
- `scripts/install_packages.R`：不足しているRパッケージをCRANからインストールします。

非公開の入力は、Stataで作成した `df03mi_surgery.dta` です。データセットは同梱していません。主スクリプトには必要な変数の一覧と確認処理があります。`trt = 1` をB群、`trt = 0` をC群、`time_os_m` を月単位の時間、`event_os = 1` を死亡として扱います。`id` は一意性の確認に使用し、出力しません。

スクリプトには、元の解析手順の対象数を確認する条件を残しています。制限前はB群83例／C群89例、元データで原発巣リンパ節転移（Primary N）、肝病変数、最大肝病変径が観測されていた患者に制限した後はB群83例／C群79例です。任意の対象数のデータセットを解析する汎用スクリプトではありません。既存の補完はこの制限前に実施されており、Rで多重代入をやり直すことはありません。

## 実行方法

Rをインストールして `Rscript` を使用できるようにし、リポジトリ直下から次のコマンドを実行します。`PRIVATE_INPUT.dta` と `PRIVATE_OUTPUT` は、利用権限のある非公開入力データと非公開出力フォルダのパスに置き換えてください。出力フォルダはリポジトリの外を推奨します。両方のパスが必須です。空白を含むパスは引用符で囲んでください。

```text
Rscript --vanilla r/scripts/install_packages.R
Rscript --vanilla r/scripts/run_wrmst_analysis.R PRIVATE_INPUT.dta PRIVATE_OUTPUT 2000 20260904
```

任意指定の第3・第4引数は、ブートストラップ反復回数と乱数シードです。既定値はそれぞれ2,000と20260904で、計算は1コアで行います。パッケージのインストールだけでは解析は実行されません。

**生成されるファイルはすべて非公開で管理してください。** 実行時のCSV、警告・セッション情報のログ、`adjustedsurv_m1.rds` はGitの対象外とする必要があります。RDSには患者単位の解析情報が含まれ、生存曲線の出力には観測されたイベント時点が使われます。同名の既存出力ファイルは上書きされるため、実行ごとに新しい非公開出力フォルダを使用してください。リポジトリの除外設定は補助的な防護策であり、生成物を公開可能にするものではありません。

## 解釈と既知の制限

- 信頼区間とp値には、補完間の不確実性が含まれていません。
- Rの安定化重みの分子には、制限後の集団の治療割合を使用します。保存されたStata重みは制限前の集団の割合を使用しているため、両者の直接的な差だけでPSの計算誤りとは判断できません。
- 記録されたPSモデルは収束しましたが、当てはめ確率が数値的に0または1になったという警告が出ています。対象の制限によって分離やpositivityに関する懸念が解消されたとは確認されていません。重みのトリミングや打切りは行っていません。
- ブートストラップではPSモデルと重みを再推定します。要求した反復の一部はRMSTの群間差に使用できませんでしたが、過去の手順では理由を分類していません。出力には制限時間ごとの有効反復数を記録します。追跡後半の観測は少なく、60か月推定値の解釈前に考慮する必要があります。
- 各群のRMST区間にはブートストラップ標準誤差と正規近似、群間差の区間にはパーセンタイル・ブートストラップを使用します。実装済みの手順をそのまま保持しています。
- 従来の `smd_*` 出力項目名はそのまま残しています。`cobalt` の呼び出しでは `binary="std"` を指定しておらず、返される差がすべて標準化されているとは限りません。論文でSMDの閾値を使う前に、指標を確認してください。
- 臨床アウトカムの起算点、共変量の測定時期、対象を制限する理由は、論文での最終的な解釈の前に研究資料との照合が必要です。

## 公開用コピーの変更点と検証

公開用コピーでは、共同研究者に固有のラベルとローカル変数名を中立的な参照表現に置き換え、入力・出力引数を明示的に必須とし、暫定的な位置づけと出力を非公開にする旨のコメントを追加しています。数値計算、対象数の確認条件、過去の参照値との比較、モデル設定は保持しています。パッケージのインストーラは変更していません。

2026-09-08の準備時レビューでは、スクリプトの点検とR構文の確認のみを行いました。患者データを用いた解析の再実行や数値の再現性の検証は行っていません。任意のWindows起動用スクリプトと表計算ソフト用の体裁調整スクリプトは除外しています。これらはRの解析結果を出力するためには必要ありません。
